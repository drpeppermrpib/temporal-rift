## Keyword research

Play indexes **title**, **short description**, and **full description** (no hidden keyword field). Prefer original framing; never use COD Zombies / Halo / DBZ brand strings.

| Tier | Keywords | Placement |
|---|---|---|
| Primary | wave survival, action RPG, offline RPG, horde survival | Short desc + full H2s + optional title A/B |
| Secondary | adaptive AI, learning enemies, skill tree, barricade defense, boss waves | Full description body |
| Brand / IP | temporal rift, ashen vanguard, aether, riftborn, emberfall | Title + first paragraph |
| Trust | no ads, no IAP, offline, no data collection | Short desc end + trust section |
| Avoid | Call of Duty, Nazi Zombies, Halo, Dragon Ball, Kakarot, Skyrim | Never in store text/graphics |
| Careful | zombie / zombies | Prefer husk / horde / undead / rift-horde |

### Competitor positioning (generic category)
You sit between offline wave-survival shooters, cover action games, and light action RPGs with skill trees. Your wedge is **adaptive enemies that punish repetition** plus **pay-once offline completeness** — say that louder than “another zombie wave game.”
