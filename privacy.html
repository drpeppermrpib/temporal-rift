Temporal Rift: Ashen Vanguard — Privacy Policy

Privacy Policy

Summary

Temporal Rift: Ashen Vanguard is a fully offline game. It collects, stores, and shares NO personal data of any kind.

Data collection

  • No personal information is collected, stored, or shared.
  • No user accounts — the game has no sign-up, login, or profile of any kind.
  • No analytics or telemetry.
  • No advertising.
  • No third-party SDKs.

Game saves

Game progress is saved only locally on your device. It never leaves your device and is removed when you uninstall the app or clear its data.

Network access

The only network request the app can make is an optional version check against GitHub's public API, used to tell you when a newer version of the game is available. This request sends no personal data — it is a plain, anonymous request for the latest published version number. The game works fully without any network connection.

Children

Because the app collects no data at all, no data is collected from anyone, including children.

Changes to this policy

If this policy ever changes (for example, if a future update adds an online feature), the updated policy will be published at this same address before the change ships.
